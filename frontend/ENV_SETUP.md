# Настройка переменных окружения для фронтенда

## Создание файла .env

В папке `OptFinance/frontend/` создайте файл `.env` со следующим содержимым:

### Для локальной разработки:
```env
VITE_API_URL=http://localhost:8000
```

### Для работы через Radmin VPN:
```env
# Замените 26.26.26.1 на реальный IP адрес вашей бэкенд машины в Radmin VPN
VITE_API_URL=http://26.26.26.1:8000
```

## Важно

1. Файл `.env` должен находиться в корне папки `frontend/`
2. После изменения `.env` перезапустите dev сервер (`npm run dev`)
3. Используйте `http://` (не `https://`) для локальной VPN сети
4. Не коммитьте файл `.env` в git (он должен быть в .gitignore)

## Проверка

После создания файла `.env` и перезапуска сервера, откройте консоль браузера (F12) и проверьте, что запросы идут на правильный адрес.
